## Solution
The name of this challenge and a simple google search give away the solution. `code.txt` is written in brainfuck and by looking at the current program, all we need to do is add a few characters to print out the correct bytes. By adding: `.>.>.>.>.>.>.>.>.>.>.>.>.>.>.` we can get the flag:

`gigem{brain_fd}`
