# Sea Shells 

Sally sold some seashells by the seashore. Try to guess how many she sold, I bet you will never be able to!

## Dev Notes
Given files: `sea_shells.c` and `sea_shells``

**Setup:**
```
sudo make docker
sudo make run
```

By default `sea_shells` is running on port 9999

**Cleanup:**
```
sudo make clean
```
