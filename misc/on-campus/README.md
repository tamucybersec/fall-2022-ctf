# On Campus

## Description

I took pictures of some of my favorite buildings on campus. Can you identify them all?

Tip: The answers you give should match the regex "[A-Z]{3,4}"<br>
ie: ABCD or ABC

## Dev notes

Yes this is an OSINT challenge that uses a docker container don't @ me

Files in `src/` are provided

Start: `make start`
Stop: `make stop`
